# HomeWork — Java Practice (Maven + JUnit)

Учебный репозиторий с моими решениями задач по Java.  
Цель — закрепить базу (ООП, коллекции, исключения, Stream API и т.д.) и прокачать навык написания чистого кода + тестов.

---

## 🧠 Что внутри
- Решения домашних/учебных заданий по темам курса Java 
- Примеры классов с инвариантами и валидацией
- Модульные тесты на **JUnit 5**
- Решение задач с CodingBat
---

## 🛠️ Стек
- **Java 24** 
- **Maven**
- **JUnit 5**
