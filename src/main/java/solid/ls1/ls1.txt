Что должен увидеть

Класс отвечает за:

валидацию;
сохранение;
отправку email;
сценарий регистрации.

Это нарушение SRP.

В данном классе есть один метод и он реализовывает валидатор входных данных.
Данный класс должен вызывать объекты, которе должны выполнять свои методы, которые они имплементируют из интерфейсов.

На какие классы можно разделить:
1. Валидатор дата (проверка на входные данные)
2. Сохранение пользователя в память (сохранение объекта)
3. Сохранение объекта в бд
4. Отправка письма.
